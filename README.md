# 🚀 RocketSwim Gear Guider

Equipment requirements guide for [RocketSwim](https://rocketswim.com) competitive swim club parents.

**Live:** [https://a-aronriley.github.io/RocketSwimGearGuider/](https://aaronrileysalesforce.github.io/RocketSwimGearGuider/)

## What It Does

- Select your swimmer's current and target competitive level
- See exactly what gear is required (and optional) for that level
- Check off gear you already own — see only what you still need
- Get buy links to approved stores (Splashables, TeamAquatics, etc.)
- Email payment requests for club gear to payments@rocketswim.com
- Copy Discord messages for coach-provided items

## Competitive Levels

J3 → J2 → J1 → S3 → S2 → S1 → CMS → MS → MSIC → Masters

## Tech

Static HTML/CSS/JS — no backend, no build step. Hosted on GitHub Pages.

Gear data lives in `data/gear-data.json` — see [Admin Guide](admin/README.md) for editing instructions.
